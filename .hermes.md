# JobTicketMockup

**Job ticket / quote sheet generator** — creates formatted PDF job tickets for WAC production jobs, organized by material and process.

**Live:** https://4003player.github.io/JobTicketMockup/  
**Repo:** https://github.com/4003player/JobTicketMockup.git  
**Stack:** Single-file `index.html` (~965 lines) + `konami.html`, no build step, GH Pages hosted.

## Architecture

- **pdf-lib** — PDF generation for the job ticket output

## What It Does

1. User enters job details: parts, materials, quantities, processes, finishing
2. Parts are grouped by **material + process** (NOT by size)
3. Generates a formatted PDF job ticket

## Layout Rules

1. **Parts grouped by material + process** — not by size or sequence
2. **Drawdowns at BOTTOM** — for shop floor reference
3. **Roll stock in linear inches** — not square footage
4. **+15% waste** — built into material calculations
5. **Finishing in part header only** — don't repeat in every line item

## Key Functions

- `generatePDF()` — main PDF generation
- `renderPart()` / `showPart()` — part rendering
- `drawSubstrate()` / `drawTable()` / `drawSummary()` — PDF layout helpers
- `pageHeader()` — consistent page headers
- `switchView()` — toggle between edit and preview

## Style

Apple light theme matching all WAC tools.
